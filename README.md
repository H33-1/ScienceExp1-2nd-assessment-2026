# 과학탐구실험1 수행평가 접속 주소

[학생용 접속 주소](https://h33-1.github.io/ScienceExp1-2nd-assessment-2026/)를 열면 [학교 계정의 Apps Script 웹앱](https://script.google.com/macros/s/AKfycbyYqV14q7ONRAGwmQA0oyaAzBxNJ3knGdtJO9s5y7i4SikRhivAzoOyxMo8Nh0pnd8/exec)으로 바로 이동합니다. 답안과 사진은 GitHub에 저장되지 않습니다. 제출 처리는 Apps Script가 담당하며, 기존 교사용 Google Sheets와 Google Drive 폴더를 사용합니다.

Apps Script 웹앱을 새 주소로 재배포하면 `index.html`의 세 URL(`meta refresh`, 링크, JavaScript가 읽는 링크)을 새 `/exec` 주소로 바꿔 주세요. 기존 배포를 새 버전으로 수정하면 주소를 유지할 수 있습니다.
